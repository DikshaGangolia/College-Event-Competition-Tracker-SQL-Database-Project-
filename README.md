## 🎓 Project Title: College Event & Competition Tracker (SQL Database Project) 🗂

I’m excited to share my latest SQL-based project — College Event & Competition Tracker — a database system designed to manage and analyze college-level events and competitions efficiently.

## 💡 Project Overview:

This project focuses on simplifying the management of college events, student registrations, results, and notifications through a structured SQL database. It allows institutions to easily track participation, winners, and event performance with meaningful analytics.

## 🧩 Key Features:

✅ Store and manage details of events (Technical, Cultural, Sports)
✅ Register students for multiple events
✅ Record and display results and winners
✅ Track event popularity and participation statistics
✅ Manage notifications and updates for schedule changes

## 🛠 Tech Stack:

Database: MySQL
Language: SQL

Concepts Used: Primary & Foreign Keys, Joins, Aggregation, GROUP BY, Relationships

## 📊 Core Tables:

Students, Events, Registrations, Results, and Notifications

🔍 Sample Queries:
Count total participants per event
Display winners with scores
Find the most popular event based on registrations

strengthen my database design, relational modeling, and SQL query optimization skills — bringing real-world college management workflows into a digital system.
